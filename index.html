Lots

Gérer les lots (regrouper, renommer)
Regrouper : toutes les bêtes du lot passent dans l'autre lot, et ce lot disparaît. Renommer : les bêtes ne bougent pas, seul le nom change. Le total du troupeau ne change pas.

Groupes

Gérer les groupes (vider, supprimer)
Vider : le groupe reste, sans brebis (pour le refaire). Supprimer : le groupe disparaît. Les lots ne bougent pas.
